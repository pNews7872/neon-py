# NEON LINES — 선으로 그리는 수학

규칙 하나로 선을 계속 이어 그리는 네온 드로잉 모음입니다.
메인 화면(`index.html`)에서 원하는 그림을 골라 들어가요.

## 01 · π WALK (`pi/`)
원주율의 자릿수(0~9)마다 360°를 10등분한 각도(n × 36°)를 정해두고,
3 → 1 → 4 → 1 → 5 … 순서대로 그 방향으로 선을 이어 그립니다.

- 360° 원판이 펜 끝을 따라 움직이며 바늘을 돌린 뒤 선을 긋습니다
- 절대 방향 / 상대 회전 모드 (지금까지 그린 선을 즉시 다시 계산)
- 속도 0.5 ~ 20,000 줄/초, 원주율은 브라우저에서 직접 100만 자리까지 계산 (Chudnovsky 공식)

## 02 · DRAGON CURVE (`dragon/`)
지금까지 그린 선 전체를 끝점 기준으로 90° 돌려 이어 붙이고,
그 전체를 또 90° 돌려 붙이기를 반복하는 드래곤 커브(Heighway dragon)입니다.

- 회전하는 모습을 애니메이션으로 보여줍니다 (회전 시간 0.15 ~ 5초)
- 최대 20세대 (선 1,048,576개), 시계/반시계 방향
- 색칠 방식: 세대별 / 선 순서 그라데이션 / 색 구역

### 무한 모드 (`dragon/infinite.html`)
- **GPU(WebGL2) 렌더링**: 매 프레임 정확한 배율로 새로 그려 끊김 없이 이어지는 무한 줌 (PC·모바일)
  - 템플릿 곡선 인스턴싱: CPU가 화면 속 큰 선분만 고르고 GPU가 각각을 2^10개 선으로 펼침
  - 지오모핑: 마지막 접힘을 0~100% 연속 조절해 세대 경계가 보이지 않음
  - MSAA + 가산 혼합(HDR) + 듀얼 카와세 블룸 + 색 보존 톤매핑
  - 자동 품질 조절: 촘촘함을 연속으로 낮추고 올려서 품질이 바뀌는 순간도 티 나지 않게
  - WebGL2가 안 되면 아래의 루프·타일 방식으로 자동 전환 (`?gl=0`으로 강제 가능)
- 끝없이 확대·축소되는 드래곤 커브: 계속 축소 / 멈춤 / 계속 확대(곡선 위를 따라 파고듦)
- 무한 루프: 시작점 기준 2배 확대 = 90° 회전한 같은 그림이라는 자기 닮음을 이용해, 그림 한 장으로 끊김 없이 무한 반복 (액자 속 액자 합성)
- 선을 저장하지 않고 화면에 보이는 부분만 나무 구조로 내려가며 계산 (세밀도 1~48px, 4px 이하는 픽셀 단위로 직접 찍음)
- 자동 확대·축소는 화면 정중앙(＋ 표시) 기준, 계속 확대 시 곡선 따라가기 토글
- 기준 선분을 화면 크기 근처로 계속 옮겨 다녀서 숫자 정밀도 한계 없이 무한 확대/축소
- 자유 탐색은 타일 피라미드 방식: 384px 타일을 여러 Web Worker가 나눠 그리고 재사용, 확대하면 4개로 쪼개고 축소하면 큰 타일로 합침 (한 단계 큰 타일을 먼저 깔아 빈 곳 없이)
- 화면 회전 보정 토글: 끄면 자기 닮음 때문에 소용돌이처럼 돌고, 켜면 방향 고정

## 03 · RECAMÁN (`recaman/`)
0에서 시작해 n번째에는 n만큼 뒤로 가고, 0 이하이거나 이미 나온 숫자면 대신 n만큼 앞으로 가는
레카만 수열을 반원으로 위·아래 번갈아 이어 그립니다.

- 느린 속도에서는 펜이 반원을 그리며 그 단계의 계산(뒤로 / 이미 나옴 → 앞으로)을 보여줌
- 속도 0.4 ~ 2,000 개/초, 최대 20,000개, 색칠: 순서 / 앞·뒤 / 색 구역, 수직선 눈금

## 공통
- 네온 그라데이션 색 조합 5종 (네온 무지개·사이버펑크·오로라·선셋·시드 랜덤), 시드 입력/랜덤
- 주소창 링크에 설정이 저장돼서 공유하면 같은 그림이 열립니다
- 화면 주변까지 넓게 미리 그려둔 이미지를 옮기고 늘리는 방식이라 이동·확대 중엔 다시 그리지 않음
  (다시 그리기는 Web Worker 백그라운드에서)
- 드래그 이동, 휠·핀치 확대/축소

단축키: `Space` 재생/정지 · `→` 한 단계 · `R` 처음부터 · `F` 따라가기 · `A` 전체 맞춤 · `S` 랜덤 시드 · `+`/`-` 확대/축소
