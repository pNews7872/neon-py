# π WALK — 원주율 네온 드로잉

원주율의 자릿수(0~9)마다 360°를 10등분한 각도(n × 36°)를 정해두고,
3 → 1 → 4 → 1 → 5 … 순서대로 그 방향으로 선을 이어 그리는 사이트입니다.

- 360° 원판이 펜 끝을 따라 움직이며 바늘을 돌린 뒤 선을 긋습니다
- 검정 바탕 위 유기적인 네온 색 구역마다 선 색이 바뀝니다
- 절대 방향 / 상대 회전 모드 전환 (지금까지 그린 선을 즉시 다시 계산)
- 속도 0.5 ~ 20,000 줄/초, 드래그 이동, 휠·핀치 확대/축소
- 원주율은 브라우저에서 직접 100만 자리까지 계산 (Chudnovsky 공식)

단축키: `Space` 재생/정지 · `→` 한 칸 · `R` 처음부터 · `F` 따라가기 · `A` 전체 맞춤 · `+`/`-` 확대/축소
